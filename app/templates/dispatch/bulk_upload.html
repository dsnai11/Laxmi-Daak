📖 How to use Bulk Dispatch?

  1. Click on the Download Template Excel button above to download the pre-formatted template spreadsheet.
  2. Fill in the spreadsheet rows. Column headers marked with (Required) in the template instructions are mandatory:
    • Sender Name, Receiver Name, Receiver Email, Item Description
    • Receiver Branch Code: Must match a valid code (e.g. JP, DL).
  3. Ensure numeric columns like Weight (kg) contain only numbers (e.g. 1.5) and no letters.
  4. Save the sheet as an Excel file (.xlsx), upload it here, and click Upload & Dispatch. System will automatically generate QR labels, record dispatches, and alert receivers.
